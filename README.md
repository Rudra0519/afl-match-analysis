# AFL Match and Fixture Analysis

An individual Power BI project by Rudra Patel, currently in progress.

## Current implementation

The supplied report contains one League Overview page with completed matches, home win rate, average match margin, wins by team, and season/finals filters. Open `afl.pbix` in Power BI Desktop to inspect the report and model.

## Planned development

Add a SQL database and queries for season performance, home advantage and rolling form; validate table grains, match keys and relationships; extend the dashboard with team comparisons. SQL implementation and Elo predictions are not included in this version.

## Verification and limitations

The saved report definition has been inspected. The report has not been refreshed during portfolio preparation. Source CSV files and collection/transformation scripts were not supplied with this PBIX, so a fresh end-to-end data refresh cannot yet be reproduced from this repository. Data provenance, season coverage, calculation checks and dashboard findings remain to be documented.
